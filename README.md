## About Me

I'm a Computer Science student focused on full-stack mobile development and applied machine learning. I enjoy connecting well-designed ML backends to fast, responsive mobile interfaces — and shipping software that's genuinely usable, not just functional.

- 📱 **Core focus:** Cross-platform mobile apps with React Native and Expo
- 🤖 **AI/ML:** Computer vision, predictive modeling, and ML-powered APIs in production
- 💡 **Approach:** Clean, scalable, well-documented code
- 🌱 **Currently exploring:** LLM-powered mobile tooling and on-device inference
